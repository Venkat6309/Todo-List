# 📝 To‑Do List Application

An interactive, minimalist, and responsive **To‑Do List** web app to help you manage your tasks effortlessly.

---

## 🎯 Features

- **Add Tasks**: Quickly add new tasks to your todo list.  
- **View Modes**:
  - **All**: View every task.
  - **Pending**: See only tasks not yet completed.
  - **Completed**: Review tasks you’ve marked done.
- **Toggle Completion**: Mark tasks as completed or revert them to pending.
- **Clear Completed**: Remove all tasks that you’ve marked as completed with one click.
- **Responsive & Clean UI**: Works smoothly across devices (desktop, tablet, mobile).

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Edge, Safari, etc.). Nothing else to install.

### How to Run Locally

1. Clone or download the repository:

   ```bash
   git clone https://github.com/venkat6309/Todo-List.git
   cd Todo-List
   ```

2. Open `index.html` in your browser:

   ```bash
   open index.html
   # or double-click the file in your file explorer / finder
   ```

3. Start managing your tasks!

## 🛠️ Usage

1. **Add a task**: Type into the input box then press Enter or click an add button.
2. **Toggle completion**: Click the checkbox or task itself to mark it done/undone.
3. **Filter view**: Switch between All, Pending, or Completed views.
4. **Clear completed**: Use the button to remove all tasks you’ve finished.
